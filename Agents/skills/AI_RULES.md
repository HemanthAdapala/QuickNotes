## Pre-Implementation Checklist

Before changing code, verify:

- I understand the task.
- I have read all project documentation.
- I know which files need modification.
- I am not accidentally using code from another project.
- I am not making assumptions.
- My changes are minimal and reversible.

If any answer is "No", stop and ask the user.

Never search Gravity Notes.

Never copy code from Gravity Notes.

Only use files inside this repository.

ask whether it should be migrated or removed.

ask first.
