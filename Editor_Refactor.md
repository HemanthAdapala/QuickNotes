# Quick Notes Editor Refactor

## Vision

Build a premium mobile note editor inspired by Apple Notes and Samsung Notes.

The editor should feel invisible.

Users should never think about the editor itself—they should only think about their ideas.

Core principles:

- One continuous writing surface
- Native mobile interactions
- Intelligent cursor behavior
- Beautiful spacing
- Fluid scrolling
- Dynamic layouts
- Premium responsiveness
- Stable architecture
- Delightful micro interactions
