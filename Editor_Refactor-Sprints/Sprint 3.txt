🚀 Sprint 3 — Scrolling Engine
Vision

Build a scrolling system that always understands where the user is writing and keeps the editing experience comfortable, predictable, and uninterrupted.

The user should never have to manually fight the screen just to see what they're typing.

In one sentence:

The document should follow the writer, not the other way around.

🎯 Goal

Transform scrolling from a passive gesture into an intelligent system that continuously supports writing.

This sprint is not about adding features.

It is about making every typing session feel effortless.

Scope

Sprint 3 focuses exclusively on scrolling behavior.

Do not implement:

Image insertion improvements
Rich content
Layout redesign
Selection improvements
Formatting changes
Animations

Thousands of words
Large documents

Requirements:

Stable 60fps scrolling.
No dropped frames.
Efficient viewport rendering.

9. Natural Momentum

Scrolling should feel native.

Requirements:

Respect Android scrolling physics.
Smooth deceleration.
No artificial snapping.
No fighting the user's gestures.
Acceptance Criteria

Sprint 3 is complete when:

Cursor never disappears while typing.
Keyboard never hides active content.
Long notes remain smooth.
Auto-scroll feels invisible.
Manual scrolling is respected.
Bottom of document feels spacious.
Reading and writing both feel natural.
